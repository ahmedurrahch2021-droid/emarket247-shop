# eMarket247 pure static source

This folder is the readable HTML/CSS/vanilla-JavaScript source intended for the Hostinger File Manager package. HTML pages live in `en/` and `bn/`; common CSS is in `assets/css/site.css`; behavior is in `assets/js/site.js`; approved product records will be published to `assets/data/`. Image files are copied into `assets/images/` only during the final static packaging step.
