Hosting & Infrastructure

Hostinger MySQL Database Integration

Hostinger MySQL Connection Settings

Enter the database details from your Hostinger hPanel (Databases → Management). These are saved in api/config.php and synchronized with the frontend.

Hostinger phpMyAdmin Schema

Execute this SQL schema in your Hostinger phpMyAdmin (SQL tab or Import tab) to create the tables instantly.

-- 1. Users Table
CREATE TABLE IF NOT EXISTS `emk_users` (...);

-- 2. Products Table
CREATE TABLE IF NOT EXISTS `emk_products` (...);

-- 3. Orders & Inquiries Table
CREATE TABLE IF NOT EXISTS `emk_orders` (...);

-- 4. Settings Table
CREATE TABLE IF NOT EXISTS `emk_settings` (...);
📥 Download database.sql

Deployment Steps to Hostinger:

  1. Create MySQL Database in Hostinger hPanel.
  2. Click Enter phpMyAdmin and import database.sql.
  3. Upload the site files to your public_html/ directory.
  4. Verify public_html/api/config.php matches your DB user and password.
